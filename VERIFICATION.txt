  Undo history had no budget and could crowd out the page's own autosave,

Building together with agents, 2026-10-09 (Claude)
  serve.py: an agent channel. An editor with a page open waits for agents'
    requests (long-poll, 25s, only while its tab is showing) and answers each;
    an agent's request waits up to 30s for the answer. Editors have an id and
    say when they've gone (a beacon on hide or close; Firefox sends those with
    Origin "null"), so agents are told at once that nobody has the page open,
    with the address to ask the person to open. Agents use a key (data/
    agent.json; the editor gets it, and can make a new one) as a bearer token,
    instead of the password. /mcp is MCP over HTTP (one JSON answer per
    request; GET and DELETE 405) with clay_pages, clay_new_page,
    clay_read_page and clay_change_page; the MCP client's name becomes the
    agent's name (claude-code is Claude). The same as plain HTTP under
    /api/agent/. Nothing in the data folder is served as a file any more
    (before, a data folder inside the app folder served site.json, and would
    have served the key).
  agent.js (loaded on server pages, not in hidden ones): reads the page as
    pieces with ids, kinds, desktop positions, words in parts, links and
    colours; applies place, text, link, add (fresh, or like an existing
    piece), remove, paint, pin, group, ungroup and canvas. A request is one
    step labelled "<agent>: <what it said>", all or nothing (restored on the
    first error, which is named), held while the person is mid-gesture or a
    dialog is open, refused in the phone layout. Touched pieces light up;
    "<agent> is here" shows for two minutes. The Agent dialog gives the Claude

  studio.js: mark / textNow / linkNow / removeNow, so several changes are one
