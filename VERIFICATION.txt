Limits
  No physical phone/touch or Safari testing. Gecko (Firefox engine): see the
  Waterfox pass below.
  Polygon lasso selection is unit-tested; the actual UI test used a rectangle.
  Alt-drag peeling and mid-stroke Escape cancellation: exercised in the
  Waterfox pass below.
  Collision handling cannot create space in an overfilled canvas; unresolved
  overlaps are reported. It is not a general responsive constraint solver.
  Group wrappers occupy their bounding rectangle, including internal gaps.
  The agent handoff is exported text, not a live agent connection.
  This is a single-page prototype, not a multi-page site builder.
  No GitHub upload or public deployment was performed.
