Limits
  No physical phone/touch or Safari testing. Gecko (Firefox engine): see the
  Waterfox pass below.
  Polygon lasso selection is unit-tested; the actual UI test used a rectangle.
  Alt-drag peeling and mid-stroke Escape cancellation: exercised in the
  Waterfox pass below.
  Collision handling cannot create space in an overfilled canvas; unresolved
  overlaps are reported. It is not a general responsive constraint solver.
  Group wrappers occupy their bounding rectangle, including internal gaps.
  The agent handoff is exported text, not a live agent connection.
  This is a single-page prototype, not a multi-page site builder.
  No GitHub upload or public deployment was performed.

Storage fix, 2026-10-08 (Claude)
  Found in use: after adding a photo, the editor reported that browser
  storage was full, so recent changes were not saved. Cause: the saved
  Undo history had no budget and could crowd out the page's own autosave,
  and Add image stored photos at full size (history kept a second copy).
  studio.js: the page saves first; if storage is full, saved history is
    dropped and the page saved again. Saved history is kept under about
    1.5 million characters (fewer steps when needed).
  studio.js / sculpt.js: Add image scales photos to 1600 pixels like Replace
    image (ClayBridge.shrink); large PNGs are written as WebP, which keeps
    transparency. Raster files up to 25 MB are accepted; SVG and GIF up to
    4 MB, unchanged.
  Headless Waterfox 153, real input: 5/5. A 4 MB, 3000x2000 photo went in at
    1600x1067 (about 1 MB); 25 moves all saved with history inside its
    budget; with storage filled to the brim the next move still saved; after
    reopening the last move was there and Undo stepped back. Regression:
    split 6/6, revision 9/9, Sculpt 30/30, groups 8/8, Layout tools and
    classic 13/13, npm test 22/22.

Idle motion and hover reveals, 2026-10-08 (Claude)
  studio.js: Idle motion presets (Float, Bob, Sway, Breathe, Spin, Scuttle)
    in the inspector and Ctrl+K. Keyframes animate four registered custom
    properties; a moving piece applies them through translate, rotate and
    scale, so hover transforms still add on top and a :root rule keeps the
    motion over the phone layout's resets. Each piece gets its own phase.
    Keyframes are defined only under prefers-reduced-motion: no-preference.
    Motion pauses while a piece is held or measured (data-clay-drag), so
    gestures never pick up a mid-motion offset.
  studio.js: Opacity in the inspector, in any state; hover opacity is also
    written under @media (hover: none), so touch screens show what hover
    reveals. Hover Move gains Grow and Tilt. Inline words (a <small>, a link)
    can be selected inside a selected box, for styling only.
  sculpt.js: measuring and held gestures pause idle motion.
  Low Tide Club, headless Waterfox 153, real input: 8/8, plus 2 environment
    checks. Scuttle, Sway and Breathe on the split crab, anemone and sea
    star move in the editor, after a drag (their own rules untouched), in
    the export (no scripts) and on a 390px phone; the hermit crab card's
    Latin name is hidden until the card is hovered on the export, with a
    real pointer; under reduced motion nothing moves; on a touch screen the
    name simply shows; after reopening, undo restores the split drawing
    exactly. Headless Firefox reports a touch screen by default, so the
    harness now declares a mouse (and a touch screen for the touch check).
  Regression: split 6/6, revision 9/9, storage 5/5, Sculpt 30/30, groups
    8/8, Layout tools and classic 13/13, npm test 22/22.
